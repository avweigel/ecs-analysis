How to use this page

Each row below is one EM crop. Two things you can do. Rows with a yellow background still need an anatomical region — those are the ones we'd most like you to fill in.

  1. View a crop in Neuroglancer Click the blue crop ID in the left column (e.g. crop1033). A new tab opens in Neuroglancer with five layers: em (raw image, on by default), all (color-coded full segmentation, on by default), and cell / ecs / bm (off by default — click the eye in Neuroglancer's left panel to toggle).
  2. Add or edit an anatomical region / description Click any cell in the Anatomical region, Region group, or Description column. The cell turns into a text box. Type, then click outside (or press Enter for short fields). Press Esc to cancel an edit without saving. Edited cells get a yellow background so you can see what you've changed.

    Use these guidelines:
    • Anatomical region — the specific structure shown (e.g. "Bile canaliculus between hepatocytes").
    • Region group — a short category that groups similar crops (e.g. "Bile canaliculus"). Match the existing values where possible so we can compare Chemical vs HPF crops with the same group label.
    • Description — a longer free-text note about what's notable (cell types present, orientation, anything unusual).
  3. Send your edits back Type your name in the Annotator box up top (this gets attached to each row in the export). Then click Download CSV. A file named crop_annotations_edits_…csv downloads to your computer. Email or Slack that file to Aubrey — she'll merge it into the master annotation list.
⚠️ Important: your edits live in this browser only. They aren't synced anywhere. Two consequences:
  • If you clear browser data, use private/incognito mode, or switch to a different computer, your edits will not be there.
  • Two people editing simultaneously will not see each other's edits — each sends their own CSV and Aubrey merges them.
Best practice: hit Download CSV when you finish a batch, even if you plan to come back — it's a backup.
