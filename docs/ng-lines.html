Step by step

Annotations out of Neuroglancer

  1. Draw the annotations in Neuroglancer with an annotation layer’s tools: point, line, bounding box, ellipsoid or polyline.
  2. Copy the whole address from the browser’s address bar. The annotations are stored in the address itself, so copy it again after any change.
  3. Paste it into the first box. Each kind of annotation gets a table: Download CSV saves it, Copy puts it on the clipboard for Google Sheets or Excel.

Spreadsheets back into Neuroglancer

  1. Edit the CSV files if you want to: change coordinates, delete rows, add rows. Keep the column names and nanometres, and save as CSV. An id is optional; the rows of one polyline share an id, or start again at vertex 1.
  2. Drop the files into the second box, all at once.
  3. Choose what to show them on: the view saved in the spreadsheet (its neuroglancer url column), a link you paste, one of this study’s datasets, or nothing else.
  4. Open in Neuroglancer, or Copy link. That link holds the annotations; keep it to open them again.

When the view already has an annotation layer with the name in the layer column, the files replace that layer’s annotations of the same kinds, and everything else about the layer stays: its other annotations, its linked segmentation layer, its properties and colours. Otherwise a new annotation layer is added. Segments come back as linked segments, and property columns come back as property values when the layer defines those properties; any other extra column is listed and left out.

Saving annotations in Neuroglancer

Annotations drawn in Neuroglancer are stored in the link, in everything after #!, so copying the address when you finish is how you save them, and opening that address brings them back. Long links are fine in a document or a notebook, but some chat apps cut them short; the JSON from Neuroglancer’s { } button holds the same thing and can be pasted here instead. A link that points at a saved state file (#!gs://…, #!https://…) does not carry the annotations itself: open it in Neuroglancer and copy the JSON.

What each spreadsheet holds

One file per type of annotation in the link, with coordinates in nanometres from the layer’s coordinate space.

TypeColumns
Linesstart z, y, x · end z, y, x · length
Pointsz, y, x
Boxesmin z, y, x · max z, y, x · size along z, y, x
Ellipsoidscenter z, y, x · radius along z, y, x
Polylinesone row per vertex: vertex number, z, y, x, and the distance along the polyline to that vertex

Every file starts with the layer and the annotation id, and ends with the segments Neuroglancer linked to the annotation (several are joined with ;), the full link, the description typed on the annotation, and one column for each property the layer defines. The lines file uses the column names annotation-processing-utils reads. Copy puts the same table on the clipboard, ready to paste into Google Sheets or Excel.

Only annotations stored in the link itself (local annotation layers) are read, not ones served from a separate annotation source. Both directions also run from the command line, in the repository: scripts/ng_lines_to_csv.py writes the same files as this page, and scripts/ng_csv_to_link.py builds the same link.
