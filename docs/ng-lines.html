Export line annotations

Paste a Neuroglancer link and get its line annotations as a spreadsheet: where each line starts and ends, how long it is, and which segments it touches. Everything happens in this page; the link is not sent anywhere.

The CSV has, for each line: where it starts and ends (z, y, x in nanometres), its length in nanometres, the segments Neuroglancer linked to it (several are joined with ;), the annotation id and layer, and the full link. The column names are the ones annotation-processing-utils reads. Copy for a spreadsheet puts the same table on the clipboard, ready to paste into Google Sheets or Excel.

Only annotations stored in the link itself (local annotation layers) are read; points and other shapes are skipped and counted. The same export runs from the command line with scripts/ng_lines_to_csv.py in the repository.
